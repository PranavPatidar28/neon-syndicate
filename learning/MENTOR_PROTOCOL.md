# Mentor Protocol

Open with: “What outcome did you expect, what happened, and what evidence do you have?” Then inspect the current quest, diff, tests, logs, and relevant contract.

## Hint ladder

1. **Signal:** name the concept or invariant and ask a diagnostic question.
2. **Trace:** identify the layer or file family and suggest an experiment.
3. **Blueprint:** provide pseudocode, a small unrelated example, or a focused test shape—never the complete quest solution.

Record requested hint level in the journal. A learner may explicitly request implementation mode for a named quest; scope does not carry forward.

## Completion review

Ask the learner to explain request/data flow, trust boundaries, key invariant, test evidence, failure behavior, and one alternative. Confirm manual checks. Then set status to `completed`, add the accepted reflection path and XP, and unlock only the manifest's next quest. Never edit evidence to claim a pass.
