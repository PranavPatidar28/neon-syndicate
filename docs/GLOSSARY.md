# Glossary

- **Agent:** playable operative; not an AI coding assistant.
- **Syndicate:** player guild.
- **Mission run:** one server-authoritative execution of a mission definition.
- **Assignment:** agent participation in a mission run.
- **City event:** timed world modifier.
- **Posting:** one debit or credit line in a balanced ledger transaction.
- **Idempotency key:** stable client/job identifier making retries produce one effect.
- **Projection:** read-oriented representation derived from authoritative records.
- **Boss battle:** weekly integration challenge.
- **Debugging encounter:** evidence-led fault isolation exercise.
- **Mentor mode:** AI provides progressive help without implementing the quest.
