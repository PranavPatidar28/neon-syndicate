# Project Brief

Neon Syndicate is a fictional co-op strategy RPG. Players operate agents in a persistent city, form syndicates, equip inventory, run asynchronous missions, react to city events, and exchange value through an auditable economy.

## Product principles

- Solo onboarding works; cooperation creates deeper strategy rather than blocking basic play.
- Outcomes are server-authoritative and explainable.
- Failure is recoverable: mission losses, retries, and outages do not silently corrupt state.
- Administrative power is explicit, least-privileged, and audited.
- The game contains no real intrusion tooling and never executes user-submitted code.

## Portfolio outcome

The final demo must show registration, agent creation, syndicate cooperation, delayed mission resolution, live updates, economy history, admin controls, and operational evidence. The case study must distinguish implemented behavior from future ideas.
